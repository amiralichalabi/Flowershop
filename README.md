# یونی‌فلاور (Flowershop)

سایت فارسی (RTL) فروشگاه گل با شعبه‌های دانشگاهی و طراح سه‌بعدی ده‌مرحله‌ای دسته‌گل و باکس گل.

- `index.html` : نسخه‌ی نهایی (v5)، تک‌فایل و آماده‌ی اجرا
- `versions/` : نسخه‌های v4 و v5
- `src/` : سورس ماژولی (data, engine, scene, viewer, app, fx) و `build.py`

ساخت دوباره: `python3 src/build.py` (فایل `index.html` را تولید می‌کند).

قیمت‌ها تخمینی‌اند و در `PRICES` داخل `src/data.js` تنظیم می‌شوند. Three.js r128 از CDN بارگذاری می‌شود.
