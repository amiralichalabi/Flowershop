# یونی‌فلاور (Flowershop)

سایت فارسی (RTL) فروشگاه گل با شعبه‌های دانشگاهی و طراح ده‌مرحله‌ای دسته‌گل و باکس گل.

نسخه‌ی ۶ با **عکس واقعی گل‌ها**: دسته‌گل یا باکس از روی عکس‌های جدا‌شده‌ی گل، کاغذ، روبان و باکس روی بوم چیده می‌شه.

- `index.html` : نسخه‌ی نهایی (v6)، تک‌فایل و بدون وابستگی خارجی
- `assets/` : عکس‌های جدا‌شده (WebP شفاف) که داخل `index.html` هم جاسازی می‌شن
- `src/` : سورس (data, photo, app, fx) و `build.py`
- `legacy-3d/` : موتور سه‌بعدی نسخه‌ی v4/v5 (Three.js)
- `versions/` : نسخه‌های قبلی

ساخت دوباره: `python3 src/build.py`

قیمت‌ها تخمینی‌اند و در `PRICES` داخل `src/data.js` تنظیم می‌شوند.
